# نظرات صفحهٔ اصلی

## نصب

این تغییر مستقل از تغییرات گاهنامه است. patch بر اساس فایل‌های فعلی مخزن GitHub آماده شده است.

```bash
git apply --check azarpouyan-comments.patch
git apply azarpouyan-comments.patch
npx prisma generate
npx prisma migrate deploy
npm run build
```

در محیط عملیاتی، migration را با DATABASE_URL همان پایگاه داده، قبل از شروع نسخهٔ جدید اجرا کنید. از `prisma migrate reset` استفاده نکنید.

## استفاده

در `/panel/comments` عکس، نام کامل و متن نظر را وارد کنید. نام شرکت اختیاری است. گزینهٔ انتشار، نمایش عمومی را کنترل می‌کند. عدد ترتیب کوچک‌تر بالاتر است؛ با ترتیب یکسان، جدیدترین نظر اول نمایش داده می‌شود. ویرایش و حذف از همین صفحه انجام می‌شود.

بخش «نظرات شما» زیر WhyUs در صفحهٔ اصلی قرار دارد؛ کارت‌ها در موبایل و دسکتاپ با اسکرول افقی قابل مشاهده‌اند. اگر نظر منتشرشده‌ای وجود نداشته باشد، بخش نمایش داده نمی‌شود. متن نظر همان متن سادهٔ واردشده توسط ادمین است و HTML اجرا نمی‌شود. متن نظرات در همهٔ زبان‌های سایت یکسان است؛ ترجمهٔ جداگانه به این جدول اضافه نشده است.

## ساختار

- مدل Prisma: `Comment`، نام جدول PostgreSQL: `comments`.
- روتر مستقل: `server/trpc/routers/comment.ts`، ثبت در `_app.ts` با نام `comment`.
- `getAll/create/update/delete` فقط ادمین؛ `getPublished` عمومی و محدود به نظرات منتشرشده.
- اعتبارسنجی مشترک فرم و سرور در `lib/comment-schema.ts`.
- ویرایش و حذف با `updatedAt` کنترل می‌شوند تا تغییرات هم‌زمان ادمین دیگر بازنویسی نشوند.
- فرم و کارت در `components/comments`؛ نمایش سایت در `components/site/CommentsSection.tsx`.

عکس حداکثر ۵ مگابایت و از نوع JPG/PNG/WebP/GIF است و از مسیر موجود `/api/upload` با پوشهٔ `comments` در همان ذخیره‌ساز فعلی بارگذاری می‌شود. اطلاعات نظر با tRPC ثبت می‌شوند؛ API یا وابستگی تازه‌ای برای آپلود اضافه نشده است. تنظیمات فعلی S3 کافی هستند.

مطابق رفتار آپلود تصاویر موجود پروژه، حذف نظر یا تعویض عکس، فایل قدیمی را خودکار از فضای ابری حذف نمی‌کند. تصاویر آپلودشده‌ای که فرمشان ثبت نشده نیز باقی می‌مانند؛ فایل‌های بدون استفاده را در صورت نیاز از فضای ذخیره‌سازی پاک کنید.
